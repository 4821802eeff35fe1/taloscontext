# ChannelOS — шпаргалка пользователя

> Краткая ежедневная памятка для ChannelOS v0.3.0. Подробности: [Руководство пользователя](USER_MANUAL_RU.md). Первый запуск: [Быстрый старт](QUICK_START_RU.md).

## Горячие действия

| Что нужно | Где |
| --- | --- |
| Палитра команд | **⌘K** на macOS / **Ctrl+K** на Windows/Linux |
| Создать пост | **Посты → Создать пост** |
| Сгенерировать AI-пост | **Посты → Сгенерировать с AI** |
| Проверить посты | **Подтверждение** |
| Посмотреть расписание | **Календарь** |
| Проверить фоновые ошибки | **Задачи** |
| Посмотреть AI-расходы | **Расходы** |
| Остановить Autopilot | **⌘K/Ctrl+K → Приостановить автопилот** или **Автопилот → Вручную** |
| Остановить новые слоты Schedule | **Расписания → выключить нужное расписание** |
| Кто что изменил | **Журнал аудита** |

## Основной workflow

**Telegram Account → Каналы → Набор каналов → Пост → Content Studio → Отправить на подтверждение → Подтвердить → Publish Now / Schedule → проверить публикации.**

## Статусы поста

| Статус | Что означает | Что обычно делать |
| --- | --- | --- |
| **Черновик** | Редактируется | Проверить, сохранить, отправить на подтверждение |
| **Генерируется** | AI Job идёт | Подождать / смотреть Задачи |
| **Ожидает подтверждения** | Нужен человек | Approve или Reject |
| **Подтверждён** | Готов к планированию | Schedule / Publish Now |
| **Запланирован** | Есть время | Проверить Calendar |
| **Публикуется** | Идут Publications | Не дублировать запуск |
| **Опубликован** | Все цели успешны | Готово |
| **Опубликован частично** | Есть success и failed | Исправить ошибки → Retry Failed |
| **Ошибка** | Workflow не завершился | Открыть Job/рассылку |
| **Отклонён** | Вернули на правку | Изменить → снова Submit |
| **В архиве** | Вне активной работы | Использовать для истории |

## Статусы Telegram-аккаунта

| Статус | Действие |
| --- | --- |
| **Подключён** | Норма |
| **Отключён** | При необходимости снова пройти Add Account |
| **Нужен повторный вход** | **Аккаунты → Добавить аккаунт**, войти тем же Telegram-пользователем |
| **Нужен пароль 2FA** | Завершить шаг 2FA |
| **Ограничение Telegram** | Ждать до указанного времени |
| **Ошибка** | Проверить last error и Jobs |
| **Отключён системой** | Нужен администратор |

## Здоровье канала

| Статус | Значение |
| --- | --- |
| **Работает** | Можно публиковать |
| **Нет прав на публикацию** | Выдать права в Telegram → Обновить каналы |
| **Аккаунт недоступен** | Проверить Telegram Account |
| **Ограничение Telegram** | Ждать FloodWait |
| **Недоступен** | Канал больше не доступен подключённому аккаунту |

## Если публикация FAILED

1. Откройте пост.
2. Посмотрите **Публикация по каналам**.
3. Откройте соответствующий **Job**.
4. Исправьте причину.
5. Нажмите **Retry Failed**.

**Не повторяйте весь пост**, если часть каналов уже SUCCESS.

## Если PARTIALLY_PUBLISHED

Пример: **8/10 успешно**.

- Успешные 8 не трогать.
- Исправить причины двух FAILED.
- Нажать **Retry Failed**.
- ChannelOS повторит только failed Publications.

## Если DELIVERY_UNKNOWN

Это не обычный Failed.

1. Откройте реальный Telegram-канал.
2. Проверьте, появился ли пост.
3. Если есть → **Подтвердить публикацию**.
4. Если нет → **Подтвердить, что не доставлено**.
5. Только после отметки Failed — Retry.

**Никогда не жмите Retry вслепую при Delivery Unknown.**

## Если FLOOD_WAIT

- Не удалять аккаунт.
- Не нажимать Retry много раз.
- Посмотреть время окончания ограничения.
- Подождать.
- Publication остаётся PENDING и сможет продолжиться после wait.

## AI и расходы

### Где смотреть

**Аналитика → Расходы**

Там есть:

- Сегодня;
- 7 дней;
- Месяц;
- Прогноз;
- бюджетная шкала;
- input/output tokens;
- расходы по операциям, Channel Set, категориям и провайдерам;
- самый дорогой контент.

### Стартовые defaults

- День: **50 ₽**
- Месяц: **1500 ₽**
- Макс. на пост: **15 ₽**
- Warning: **80%**

### Важно

Если AI-бюджет исчерпан, **новые AI-вызовы блокируются**, но уже одобренная Telegram-публикация не отменяется.

## AI-кнопки Content Studio

- **Переписать** — новая формулировка.
- **Сократить** — короче.
- **Расширить** — подробнее.
- **Изменить тон** — под Tone Profile.
- **Улучшить** — общая редактура.
- **Сгенерировать заголовок**.
- **Перегенерировать фрагмент** — сначала выделить текст.
- **Сгенерировать призыв**.
- **Убрать AI-клише**.

Каждый вызов может тратить AI-бюджет и создаёт новую версию.

## Channel Set

Доступные режимы:

- **Одинаковый текст (EXACT)**
- **CTA для каждого канала**
- **Контакт для каждого канала**

**ADAPTED в Web UI v0.3.0 не предлагается.**

## Schedule

Проверьте:

- timezone;
- дни;
- posts/day;
- окна;
- min interval;
- excluded dates;
- random/fixed;
- misfire policy.

Misfire:

- **SKIP** → снять время, вернуть в Approved;
- **PUBLISH_IMMEDIATELY** → отправить после восстановления;
- **RESCHEDULE_NEXT_SLOT** → перенести на следующий свободный slot.

## Autopilot

Режимы:

- **Вручную** — ничего не создаёт автоматически;
- **С подтверждением** — AI → Approval;
- **Автопилот** — AI → auto approve/schedule, кроме рискованных случаев.

Для старта используйте **С подтверждением**.

Полный Autopilot всё равно отправит в Approval, если:

- requires review;
- слишком высокий duplicate score;
- news без обязательного source.

## Media

Можно загружать:

- PNG
- JPEG
- WebP
- GIF

Реальная AI-генерация изображений через Timeweb Agent в текущем production недоступна. Галерея и Upload работают.

## Источники и идеи

Source types в текущем редакторе:

- RSS;
- URL;
- Manual URL;
- Telegram.

**Idea ≠ Post.**

Для превращения Idea в пост нажмите **Сгенерировать пост**.

## Где искать проблему

| Симптом | Сначала открыть |
| --- | --- |
| AI завис | **Задачи** |
| Telegram не отправляет | **Пост → Публикации**, затем **Задачи** |
| Нет каналов | **Аккаунты → Обновить каналы**, затем **Задачи** |
| Scheduled не вышел | **Обзор → Планировщик**, **Календарь**, **Задачи** |
| Нет картинки | **Обзор → S3**, **Галерея** |
| Большой расход | **Расходы → самый дорогой контент** |
| Непонятно, кто изменил | **Журнал аудита** |
| Language не сохранился | **Настройки → Общие**, затем reload |

## Пять правил, которые спасают от большинства проблем

1. **Не дублируйте один пост для нескольких каналов — используйте Channel Set.**
2. **Не повторяйте успешные Publications — используйте Retry Failed.**
3. **Не повторяйте Delivery Unknown до ручной проверки Telegram.**
4. **Не начинайте с полного Autopilot — сначала Approval.**
5. **Не работайте без дневного и месячного AI-бюджета.**
