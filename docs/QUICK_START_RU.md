# ChannelOS — быстрый старт

> Для версии: ChannelOS v0.3.0. Этот файл описывает пользовательский Web-интерфейс, а не установку сервера. ChannelOS уже должен быть установлен и доступен по URL.

Если вам нужно подробное объяснение каждого раздела, статуса и ошибки, откройте [полное руководство](USER_MANUAL_RU.md). Для ежедневной краткой справки есть [шпаргалка](CHEATSHEET_RU.md).

## За 5–10 минут: от пустой панели до первого поста

### 1. Войдите или создайте аккаунт

Откройте URL ChannelOS.

- Если аккаунт уже есть, введите email и пароль и нажмите **Войти**.
- Если это первый запуск нового пространства, переключитесь на регистрацию, укажите имя, email, пароль не короче 8 символов и название рабочего пространства.
- Русский язык можно выбрать прямо на экране входа. Позже он меняется в **Настройки → Общие → Язык интерфейса** или через меню аккаунта в шапке.

> Важно: язык интерфейса не переводит тексты ваших постов. Язык контента задаётся инструкцией AI и профилем «Тон и стиль».

### 2. Подключите Telegram-аккаунт

Откройте **Дистрибуция → Аккаунты** и нажмите **Добавить аккаунт**.

1. Введите номер телефона в международном формате, например +79991234567.
2. Нажмите **Отправить код**.
3. Введите код, который Telegram отправил этому аккаунту.
4. Если включена двухэтапная аутентификация, введите пароль 2FA.
5. После успешного подключения ChannelOS автоматически поставит импорт каналов в очередь.

Код подтверждения и пароль 2FA нужны только для текущего входа. Не передавайте их другим людям.

Если кнопка подключения недоступна из-за роли, обратитесь к администратору рабочего пространства: управление Telegram требует прав администратора или владельца.

### 3. Проверьте импорт каналов

Откройте **Дистрибуция → Каналы**.

После подключения аккаунта здесь должны появиться каналы, которыми он может управлять. Если список пуст:

- вернитесь в **Аккаунты**;
- нажмите кнопку **Обновить каналы** рядом с нужным аккаунтом;
- откройте **Автоматизация → Задачи** и найдите задачу импорта каналов;
- если задача завершилась ошибкой, откройте её и прочитайте причину.

Для публикации лучше использовать каналы со статусом **Работает**. Статусы **Нет прав на публикацию**, **Аккаунт недоступен**, **Ограничение Telegram** и **Недоступен** требуют внимания.

### 4. Создайте набор каналов

Откройте **Дистрибуция → Наборы каналов** и нажмите **Новый набор каналов**.

Пример:

- Название: **Talos Network**
- Описание: **Основные Telegram-каналы**
- Режим распространения: **Одинаковый текст во всех каналах**
- Каналы: отметьте нужные каналы

Доступные в текущем интерфейсе режимы:

- **Одинаковый текст** — один текст для всех каналов;
- **CTA для каждого канала** — основной текст общий, призыв может подставляться по настройкам конкретного канала;
- **Контакт для каждого канала** — основной текст общий, контакт/CTA берётся для конкретного канала.

Один набор позволяет создать один Content Item и разослать его в несколько каналов без повторной генерации AI.

### 5. Создайте пост

Откройте **Контент → Посты**.

Есть два пути:

- **Создать пост** — пустой черновик для ручного написания;
- **Сгенерировать с AI** — введите задание и, при желании, сразу выберите набор каналов.

Пример задания:

**Напиши короткий обучающий пост о том, как считать CPA перед тестом рекламной кампании. Язык — русский, без рекламных клише.**

После AI-генерации откроется **Content Studio**.

### 6. Проверьте и отредактируйте пост

В Content Studio:

1. Проверьте заголовок и текст.
2. Выберите **Набор каналов**, если не выбрали его раньше.
3. При необходимости выберите **Профиль тона**.
4. Используйте форматирование и Telegram-превью.
5. При необходимости прикрепите изображение из галереи.
6. Нажмите **Сохранить изменения**.

AI-кнопки доступны только для сохранённого текста. В текущей версии есть: **Переписать**, **Сократить**, **Расширить**, **Изменить тон**, **Улучшить**, **Сгенерировать заголовок**, **Перегенерировать фрагмент**, **Сгенерировать призыв**, **Убрать AI-клише**.

> Совет: для **Перегенерировать фрагмент** сначала выделите нужный кусок текста.

### 7. Отправьте пост на подтверждение

Для черновика нажмите **Отправить на подтверждение**.

Пост перейдёт в статус **Ожидает подтверждения** и появится в **Контент → Подтверждение**.

Откройте его и нажмите:

- **Подтвердить**, если публикация готова;
- **Отклонить**, если её нужно вернуть на доработку.

Для первых дней работы используйте именно этот ручной контроль, даже если позже планируете включить Autopilot.

### 8. Опубликуйте сейчас или поставьте в расписание

После подтверждения доступны три варианта:

- выбрать конкретную дату и время и нажать **Запланировать**;
- выбрать правило расписания и нажать **Ближайший свободный слот**;
- нажать **Опубликовать сейчас**.

Если хотите сначала настроить регулярный график, откройте **Автоматизация → Расписания**. Там можно задать дни недели, часовой пояс, количество постов, временные окна, случайное/фиксированное время, минимальный интервал и исключённые даты.

### 9. Проверьте результат публикации

После запуска публикации откройте тот же пост. Внизу Content Studio появится блок **Публикация по каналам**.

Например, для набора из 10 каналов вы можете увидеть:

**Опубликовано: 8 из 10**

Если две публикации завершились обычной ошибкой, нажмите **Повторить 2 неудачных публикации**. Успешные 8 каналов повторно не отправляются.

Если статус одной публикации — **Доставка не подтверждена**, сначала вручную проверьте реальный Telegram-канал. Только после этого выберите **Подтвердить публикацию** или **Подтвердить, что не доставлено**. Не нажимайте Retry вслепую: иначе можно получить дубль.

### 10. Посмотрите задачи, расходы и уведомления

После первого поста полезно открыть:

- **Автоматизация → Задачи** — фоновые операции, попытки, ошибки и Retry;
- **Аналитика → Расходы** — расход сегодня, за 7 дней, за месяц, прогноз и детализация AI-запросов;
- **Система → Уведомления** — ошибки публикации, FloodWait, отключение Telegram, бюджет и запросы подтверждения;
- **Система → Журнал аудита** — кто и когда создавал, менял, подтверждал, планировал и публиковал контент.

## Что настроить перед автоматизацией

Перед режимом Autopilot рекомендуется:

1. добавить все нужные Telegram-аккаунты;
2. проверить здоровье каналов;
3. собрать стабильные Channel Sets;
4. настроить CTA в **Настройки → Общие** и при необходимости переопределения в настройках каналов;
5. заполнить **Базу знаний** актуальными фактами, контактами, правилами и примерами;
6. создать профиль **Тон и стиль**;
7. установить лимиты в **Настройки → Бюджет**;
8. несколько дней работать вручную или в режиме **С подтверждением**;
9. только затем включать **Автопилот** для выбранного набора и расписания.

Безопасные стартовые значения, которые совпадают с текущими значениями по умолчанию: дневной AI-бюджет **50 ₽**, месячный **1500 ₽**, максимум на один пост **15 ₽**, предупреждение **80%**.

## Две важные особенности текущей версии

**Генерация изображений.** В production с реальным Timeweb Agent провайдер изображений сейчас недоступен, поэтому кнопка AI-генерации изображения отключена. Загрузка своих PNG/JPEG/WebP/GIF и выбор изображения из **Медиагалереи** работают.

**Режим ADAPTED.** В backend существует режим адаптации текста под каждый канал, но в текущем пользовательском редакторе Channel Set он не предлагается. Пользуйтесь тремя режимами, которые реально показаны в интерфейсе.

## Горячая команда

Нажмите **⌘K** на macOS или **Ctrl+K** на Windows/Linux. Палитра команд умеет создавать и генерировать пост, открывать календарь, добавлять Telegram-аккаунт, создавать набор каналов, открывать подтверждение, задачи и расходы, приостанавливать Autopilot и искать посты/каналы/наборы.
